# Demo play fixtures

The phrases in `docs/demo-plan.md` name these engine checks. Events use player IDs. Voice interpretation, choosing the runner, and confirmation buttons belong to later milestones.

| Demo play | Cited fixture |
| --- | --- |
| Ball | `../moraga/mustang-ball-adds-to-count.yaml` |
| Strike | `../moraga/called-strike-adds-a-strike.yaml` |
| Single to left with a runner advance | `single-to-left-with-advance.yaml` |
| Steal second | `../moraga/stolen-base-moves-only-the-runner.yaml` |
| Runner scores with two runners on | `chosen-runner-scores.yaml` |
| Scratch that | `undo-whole-single.yaml` |
| Mustang rejects a bunt | `../moraga/mustang-rejects-bunts.yaml` |
| Pitch-count warning | `../moraga/pitch-smart-warning-at-65.yaml` |
| Double for the clip | `double-for-the-clip.yaml` |

The scoring fixture records the chosen runner and the cause of the advance. It does not guess which runner the speaker meant. The undo fixture restores the in-play pitch, count, runner, score, batting order, pitch count, and threshold alert together.
